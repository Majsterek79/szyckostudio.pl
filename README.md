# Szycko Studio website

Statyczna strona wydawcy aplikacji Szycko Studio.

## Publikacja na GitHub Pages

1. Utwórz repozytorium `szyckostudio.pl` albo `szycko-studio-website`.
2. Wgraj zawartość folderu `website-szycko-studio`.
3. Włącz GitHub Pages dla gałęzi `main`.
4. W OVH ustaw DNS według instrukcji GitHub Pages:
   - rekordy `A` dla apex domeny,
   - rekord `CNAME` dla `www`, jeśli będzie używany.
5. W GitHub Pages ustaw domenę `szyckostudio.pl`.
